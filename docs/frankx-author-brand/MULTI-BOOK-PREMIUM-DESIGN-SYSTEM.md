# FrankX Multi-Book Premium Design System
**Date:** 2026-07-16  
**Scope:** All frankx.ai books + print + web components  
**Rule:** Shared tokens + per-imprint temperature. Masters are always **flat graphic covers**.

---

## 1. Long-term luxury thesis

Premium is not more decoration. Premium is:

1. **Material truth** — cloth grain, foil catch light, deep ink blacks, paper tooth  
2. **One unforgettable mark** per title (filament, tablet, compass, twin spheres…)  
3. **Type that owns the thumbnail**  
4. **Series grammar** you can spot across a shelf  
5. **Emotional temperature** tuned to the book’s job (authority / practice / rebellion / fun / grace)

Best houses (Knopf, Penguin Clothbound, FSG, Taschen, Phaidon) win with **restraint + craft**, then surprise with **one lush move**.

## 3. Attraction vs authority matrix

Every cover balances two axes. Design for the **job**:

```
                AUTHORITY
                    ▲
     Mendelsund     │     Clothbound luxury
     Swiss systems  │     Golden Age flagship
                    │
 REBEL ◄────────────┼────────────► LUSH / DESIRE
  Kidd / Moss       │     Liquid metal / foil inlay
  Off-White type    │     NFT generative wealth
                    │
                    ▼
                 WARMTH / FUN
```

- **Golden Age** → high authority + moderate lush (beautiful future, not casino)  
- **Wordless One** → authority + silence  
- **Wordless Two** → authority + practice warmth  
- **Fable** → artful + slightly rebellious  
- **Spartan** → rebel + authority  
- **Love/Poetry** → warmth + lush restraint

## 6. Quality bar (every cover)

- Flat master 1600×2560 (not book-on-table)  
- Title legible at 100px width  
- One primary attractor (type OR symbol OR material — not all three fighting)  
- Series-compatible color logic  
- ≥26/30 visual gate  
- Distinct from other imprints at a glance
