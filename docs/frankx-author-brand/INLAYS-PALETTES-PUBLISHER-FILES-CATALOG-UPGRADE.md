## 0. Publishing-house principle

A top house does not decorate books randomly. It assigns each title:

1. **Job** (authority / practice / desire / rebel / warmth / myth)  
2. **One object-mark** (inlay metaphor)  
3. **One material language** (cloth, lacquer, foil, paper white, liquid metal…)  
4. **One palette temperature**  
5. **One title architecture** (what the name promises vs what the book delivers)  
6. **One marketing spine** (who it is for + one sentence + one proof)

Premium liquid metal is a **tool**, not a default. Use it when the book’s promise is *desire, dual systems, or gift flagship*. Use cloth/type when the promise is *trust and permanence*.

## 1. What “inlay” means in book design

| Layer | Meaning | Where it lives |
|-------|---------|----------------|
| **Field pattern (L1)** | Quiet background structure (cloth, ticks, grid, twin-ring) | Cover field, spine, endpapers |
| **Object mark (L2)** | One hero metaphor object (filament, knot, compass, tablet…) | Cover center / cartouche |
| **Typographic inlay (L3)** | Title lock, chapter system, rules, numbers | Cover + interior |
| **Experience inlay (L4)** | Rituals: laws, experiments, fable seals, 90-day maps | Reading path + PDF modules |
| **Foil / deboss** | Physical metal or relief | Print specials |
| **Digital liquid metal** | Lacquer/CGI object finish | Desire editions + web art |

**Rule:** One primary **object** per title. One primary **field pattern** per title. Rituals may repeat every chapter.  
**Expanded doctrine:** `PATTERN-STRUCTURAL-INLAYS-EXPERIENCE.md` (structure, patterns, story, experience).

Premium books feel rich because they feel **architected** — pattern + object + chapter bones + ritual — not because they use more chrome.

## 2. Objects that work as premium inlays (and why)

Objects must be **legible at thumbnail**, **metaphorically true**, and **not generic AI jewelry spam**.

### Tier A — House-approved object library

| Object | Metaphor | Best for | Metal / finish | Avoid when |
|--------|----------|----------|----------------|------------|
| **Filament / tungsten wire** | 20W mind, spark, precision | Golden Age, Wordless, systems | Warm gold, tungsten | Poetry (too tech) |
| **Dual spheres (linked)** | Human + machine minds | Golden Age, Fable, CoE | Amber-rose + cyan/emerald | Pure fitness/soul books |
| **Braided knot / torus link** | Two streams becoming one | Golden Age deluxe, partnership books | Gold + emerald lacquer | Manifestation-only titles (reads crypto) |
| **Generative curve (single)** | Intelligence as elegant system | AI architecture, Pak-minimal editions | Hairline gold on void | Warmth books |
| **Open notebook + instrument** | Practice, craft, experiment | Wordless Two, Secrets, workbooks | Brass, cream paper | Pure manifesto |
| **Compass / dividers** | Direction, craft measure | Secrets, Great Transition | Brass, steel | Love poetry |
| **Tablet / blank stone** | Unnamed law, permanence | Wordless One | Marble + hairline gold | Business how-to |
| **Key / single keyhole** | Access, decision, closed doors | Decision chapters, Secrets | Aged brass | Overused self-help |
| **Mirror (simple, no face)** | AI as mirror not master | Golden Age ch.8 themes, Fable | Dark glass + silver edge | Avoid faces/reflections of people |
| **Lantern / beam** | Attention, narrowed light | Fable, study books | Amber glass, bronze | Loud tech |
| **Seed / single seed** | Ownership, long game | Great Transition, legacy | Matte gold, soil black | Short fun books |
| **Horse line silhouette** | Fire Horse, motion, yes | Fire Horse poems | Ember red-gold line | Non-year books |
| **Lotus / water line** | Love, hope, poetry | Love & Poetry, Hoffnung | Soft rose-gold, ink wash | Hard systems books |
| **Shield / iron band** | Discipline, Spartan | Spartan Mindset | Iron, gunmetal, blood-red accent | Soft poetry |
| **Ledger / two columns** | Truth, misses + wonders | Fable, integrity, CoE | Ink black, cream | Romance |
| **Lamp passed / hand-off** | Transmission, teaching | Golden Age close, Fable close | Warm gold glass | Product manuals |

### Tier B — Use sparingly (high cliché risk)

| Object | Risk | When OK |
|--------|------|---------|
| Infinity loops / Möbius | Overused crypto/AI stock | Only if extremely minimal Pak style |
| Neural nets / nodes | Corporate AI brochure | Never as primary hero |
| Robots / androids | Toy / hype | Never for FrankX authority books |
| Generic diamonds / crowns | Luxury cosplay | Never |
| Brain anatomical | Medical/stock | Prefer 20W filament instead |
| Cryptocurrency glyphs | Wrong brand | Never |

### Liquid metal forms that read intelligent (not casino)

| Form | Read | Use |
|------|------|-----|
| **Thin filament / wire** | Precision, 20W | Default systems DNA |
| **Braided dual stream** | Partnership of minds | Flagship desire editions |
| **Hairline parametric curve** | Math beauty, collector | Minimal masters |
| **Lacquer knot (limited)** | Gift ultra-premium | Special edition only |
| **Molten pool / blob** | Cheap AI | **Ban** |
| **Chrome skull / cyber face** | Genre trash | **Ban** |
| **Heavy baroque filigree everywhere** | Noise | Only micro-detail on one object |

**Liquid metal rule:** metal should feel like **one crafted object under museum light**, not a wallpaper of chrome.

## 4. Formats & design files every publisher needs

### Always create (every T1+ book)

| File | Spec | Purpose |
|------|------|---------|
| `cover-front-master.jpg` | 1600×2560 RGB, flat graphic | Web + KDP ebook |
| `cover-front@2x.jpg` | 3200×5120 | Retina / print prep |
| `cover-thumb.jpg` | 400×640 | Grids |
| `cover-og.jpg` | 1200×630 crop | Social/OG |
| `cover.spec.md` | Concept + locked type strings | Regen / agents |
| `type-lock.json` | Exact title, subtitle, author | Overlay pipeline |
| Interior MD/MDX | Chapter SSOT | Web reader |
| `epub` build | EPUB3 | Stores / email |
| `pdf-interior.pdf` | Print-ready body | Print / lead magnet |
| Claims / sources note | For science chapters | Integrity |

### When going to KDP / Ingram / house print

| File | Spec | Notes |
|------|------|-------|
| `wrap-kdp.pdf` | Full cover: back+spine+front + 0.125" bleed | From KDP calculator |
| `kdp-calculator.json` | pageCount, trim, paper, spine width | Never guess spine |
| `interior-print.pdf` | Correct trim, fonts embedded, 300 DPI images | White vs cream paper |
| `ISBN / ASIN pack` | Metadata, categories, keywords | Marketing |
| `proof-checklist.md` | Physical proof sign-off | Before ads spend |

### Optional premium editions

| File | When |
|------|------|
| Cloth + foil stamp dieline | Special hardcover |
| Dust jacket PDF | Trade hardcover |
| Endpapers pattern | Series branding |
| Limited liquid-metal digital art print | Collectors (not the master cover substitute) |
| 3D book mock PNGs | Ads only — **never** master |

### Software by stage

| Stage | Tool |
|-------|------|
| Manuscript | Markdown + git + AuthorOS |
| Flat cover art plate | NB/Gemini gen + **Figma/Canva type overlay** |
| Print wrap | Affinity Publisher / InDesign / Canva KDP template |
| Interior PDF | Typst / Pandoc / Prince |
| EPUB | Pandoc / softcover pipeline |
| Brand tokens | Figma library + design system MD |

**Markdown alone cannot own foil, wrap spines, or CMYK proofs.** MD owns **prose SSOT**; design tools own **cover + print geometry**.

## 5. Catalog architecture (stop random book soup)

### Six imprints (public face)

1. **Loving Grace Tech** — Golden Age, Great Transition, CoE/systems  
2. **Wordless / Practice** — Laws 1–2 (+ future experimental logs)  
3. **Maker** — Book of Secrets, craft  
4. **Human OS** — Self-Development, Spartan, Imagination, Manifestation (merge messaging)  
5. **Fable & Story** — Fable  
6. **Poetry & Hope** — Love & Poetry, Hoffnung/Hope, Fire Horse  
7. **Arcanea** (separate brand wall) — legends, bestiary, etc.

### Public “frontlist” vs “backlist lab”

| Tier | Count target | Examples |
|------|--------------|----------|
| **Frontlist (market hard)** | 5–7 | Golden Age, Wordless series, Fable, Great Transition, Secrets |
| **Supported midlist** | 5–8 | Self-Development, Spartan, Love, Hoffnung |
| **Lab / thin titles** | rest | Merge, rename, or keep free without heavy ads |

**House rule:** Do not market 20 titles equally. Market the frontlist; let lab titles feed them.

## 7. Marketing system (house level)

### Positioning sentence (all frontlist)
> Frank Riemer writes field manuals for a beautiful agentic future — intelligence, practice, craft, and story you can run.

### Funnel
```
Attention (X/blog/fables/poems)
  → Free web book chapter
    → Series / flagship PDF email
      → Agents packs / products / Inner Circle
        → T2 print box (later)
```

### Campaign types by imprint
| Imprint | Campaign |
|---------|----------|
| Loving Grace | Long essay + architecture proof + CoE |
| Wordless | Weekly law challenge + recognition quotes |
| Maker | Process videos / build-in-public |
| Human OS | 7-day pillar challenges |
| Fable | Single fable drops (high share) |
| Poetry | Short vertical video + gift seasons |

### Title quality bar
A title ships only if it:
1. Names a **specific promise**  
2. Is not interchangeable with 100 Amazon self-help clones  
3. Matches the **inlay metaphor**  
4. Survives thumbnail (short enough)

## 8. Production operating system (higher intelligence house)

### Roles (always on)

### Per-title pipeline
```
Brief (job, object, palette, title lock)
  → 5–10 designer-lab covers (flat masters)
  → Type lock + visual QA (title accuracy!)
  → Promote master + social + optional gift
  → Interior style by imprint
  → EPUB + PDF
  → Series links + homepage curation
  → Marketing pack (3 threads, 1 essay angle, 1 email)

```

### QA gates
- Flat master (not book-on-table)  
- Title exact  
- Object from approved library  
- Palette matches job  
- Scar + voice clean for T1  
- Claims clean for science

## 10. Answer summary (direct)

**Best liquid/metal objects:** filament, dual spheres, braided dual-stream knot (special), parametric gold curve, brass instruments — not blobs, brains, robots, or crypto infinity spam.

**Colors:** void+gold for authority; gold+cyan/emerald for dual intelligence; charcoal+brass for practice; ivory+black for quiet prestige; rose-gold for poetry; iron+ember for discipline; Arcanea sealed off.

**Formats:** flat 1600×2560 master, type-lock, thumb/OG, EPUB, interior PDF, KDP wrap only with calculator; 3D mocks for ads only.

**Catalog:** fewer public promises, stronger imprints, frontlist discipline, object+palette assigned per book, titles that aren’t generic modules.
