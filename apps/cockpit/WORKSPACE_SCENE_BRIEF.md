# Author Workspace Scene Brief

## Surface

Route: `/projects`

The workspace is the author operating room before a single book cockpit opens. It makes the product feel like Figma/Linear for books: project stack, activation-ready starter lane, manuscript-text intake, portable graph import, runtime trust, activation queue, and direct entry into each story cockpit.

## Static Composition

- Top: dense command chrome shared with cockpit, setup, ops, and billing.
- First viewport: workspace command panel plus project seed/import panel with starter template, premise, audience, and import modes.
- Middle: project stack with manuscript progress, canon count, tasks, readiness, and cockpit entry.
- Right: activation queue and runtime state.
- Bottom: trust strip connecting hosted core, setup blockers, manuscript import, starter cockpit scaffolding, and agent bridge.

## Activation Contract

- Seed mode creates an editable starter cockpit: chapters, scene cards, beats, provisional codex entries, canvas nodes, tasks, DAM brief, publishing checklist, and a decision record.
- Seed mode does not generate or apply manuscript prose.
- Import modes preserve author-provided text or graph state and route it into review tasks.
- Explicit blank creation is still supported by API for portable graph tests and local workflows.

## Motion

V1 uses static state, stable hover/focus states, and no required motion. Later motion job: show project creation flowing into cockpit without interrupting writing.

## Asset Policy

No external or generated assets are introduced. Product UI screenshots are the primary proof asset for this surface.
