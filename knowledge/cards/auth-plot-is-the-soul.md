# Plot before colour

Aristotle ranks plot over character, with a painting analogy: outline
beats confused colour.

**Agent use:** story-architect skills run structure first. Voice passes
come after a beat sheet exists.

This is a craft default, not a ban on lyric or interior work. If a
project inverts the ranking, say so in the brief.
